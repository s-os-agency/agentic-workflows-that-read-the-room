# Agentic Workflows That Read the Room — plain-language README

## What this is
A copy of an official GitHub training exercise. It teaches you to set up a GitHub automation that uses AI to draft updates to a small website, then opens a pull request (a proposed change) for a person to review.

## Who it's for
Developers and anyone curious about AI-powered automation on GitHub. You need a GitHub account with access to GitHub Copilot, basic familiarity with GitHub, and some comfort editing text settings files.

## What it does today
In under 45 minutes, the exercise walks you through:
1. Installing GitHub's "Agentic Workflows" add-on (`gh aw`) in the repo.
2. Writing an AI automation in plain Markdown. It drafts updates to a sample website for "Mona" (GitHub's mascot) using her notes, the GitHub Blog and the GitHub Changelog.
3. Running it and reviewing the pull request it opens.

GitHub's built-in automation posts each lesson step into the repo as you go.

## How to run it
Follow the steps GitHub posts in this repo's issues and Actions tab. If a step doesn't appear after about 20 seconds, refresh the page and check the Actions tab.

The exercise is designed for **public** copies. Private copies may need extra token setup.
